📦 Marketplace Backend
Проект backend-сервиса для блога маркетплейса. Реализована регистрация, JWT-аутентификация, отправка писем, работа с блоговыми статьями, комментариями, избранным, лайками, категориями, загрузкой изображений и многое другое.

🚀 Стек технологий
FastAPI — основной фреймворк

PostgreSQL — база данных

Docker / Docker Compose — окружение

Celery + RabbitMQ — асинхронные задачи (отправка писем)

MinIO (S3) — хранилище изображений

pytest — тестирование

Pydantic / pydantic-settings — валидация данных и конфигурация

JWT — аутентификация через cookie

Swagger — документация API (/docs)

🔐 Аутентификация и авторизация
Регистрация пользователя с отправкой email через Celery.

JWT сохраняется в cookie.

Middleware обрабатывает токены при каждом запросе.

Защищенные эндпоинты работают только при наличии токена.

📝 Статьи и блог
Создание, редактирование, удаление (фейковое) статей.

Пагинация, поиск (PostgreSQL full-text search), фильтрация по категориям.

Загрузка изображений в S3-хранилище (MinIO).

Категории — создание, получение списка.
